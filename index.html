EduManage Pro — v2.0
References used:
• openSIS — student database, health records, attendance
• Fedena — canteen & hostel add-on modules
• PowerSchool — grading logic, fee management, parent-student loop
• ERPNext Education — admissions, enrollment, financial accounting
• Gibbon — clean developer-centric structure
• RosarioSIS — grades, attendance, scheduling
• Canvas LMS — course progress, upcoming tasks, recent grades
• Squiz Edify — email calendar integration, credit tracking
• Dribbble School UI — dashboard design inspiration

Tech Stack: Spring Boot 3 · MySQL · JPA · Spring Security · Docker · Swagger
